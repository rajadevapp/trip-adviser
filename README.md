# Trip Adviser – Travel Website 🌍

A modern and responsive **Trip Adviser website** developed to provide users with an engaging travel experience. The website focuses on clean design, attractive destination sections, image galleries, and a smooth user interface.

The entire website is designed to be **fully responsive across different screen resolutions**, including mobile phones, tablets, laptops and desktops.

## Features

* Responsive travel website design
* Modern and clean user interface
* Travel destination sections
* Attractive image gallery
* Responsive navigation
* Flexible layouts using CSS Flexbox
* Optimized layouts for different screen sizes
* Mobile, tablet, laptop, and desktop support
* Cross-browser compatible design
* Clean and maintainable HTML and CSS

## Responsive Design

The website is developed to support different screen sizes and resolutions:

* 📱 Mobile – 320px and above
* 📱 Large Mobile – 480px and above
* 📲 Tablet – 768px and above
* 💻 Laptop – 1024px and above
* 🖥️ Desktop – 1366px and above

* The layout automatically adapts to the available screen size while maintaining proper spacing, alignment, typography, and image proportions.

## Technologies Used
